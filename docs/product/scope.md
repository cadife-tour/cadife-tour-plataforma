# Escopo e Anti-Escopo — Etapa 1 (MVP)

## Escopo Aprovado
- Landing page institucional de alto impacto visual (Next.js App Router).
- Core semântico com HTML-first.
- Progressive Enhancement (Motion e WebGL).
- Suporte a i18n (PT-BR, EN, ES) com dicionários tipados.
- Integração de conversão direta com deep links do WhatsApp.
- Fachada agnóstica de Analytics privacy-first.
- Design System semântico baseado em CSS Custom Properties.

## Anti-Escopo Estrito (O que NÃO entra na Etapa 1)
- ❌ Autenticação / Login de usuários.
- ❌ Área restrita ou painel administrativo.
- ❌ Banco de dados relacional / ORMs (Prisma, Postgres).
- ❌ CMS administrativo com interface de edição.
- ❌ Checkout / Pagamentos / E-commerce.
- ❌ Recursos de IA ou geração automatizada de roteiros.
- ❌ APIs de cotação de voos / clima (reservadas para a Etapa 2).
